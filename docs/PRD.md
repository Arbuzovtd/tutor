## Конкурентный ландшафт

| Конкурент | Что делает | Чего не делает |
|---|---|---|
| **TeachersFlow** | CRM для репетиторов в Telegram Mini App: расписание, студенты, оплаты, уведомления | Не отвечает за репетитора. Студент должен регистрироваться. Нет Chat Automation. Нет AI-агента |
| **respond.io / SleekFlow** | Универсальные мессенджер-CRM для бизнеса | Дорого ($30–200/мес), не заточены под репетиторов, нет нишевой логики |
| **OkiBot** | Конструктор ботов для школ | Без AI, без Chat Automation, нужен разработчик |

**Ключевое отличие TutorBot:**
- TeachersFlow = инструмент который помогает репетитору управлять.
- TutorBot = агент который управляет вместо репетитора.
- Студент ничего не устанавливает — просто пишет в Telegram как обычно.

---

## Что это

SaaS-сервис для репетиторов-одиночек. Подключается к Telegram-аккаунту репетитора через **Chat Automation** (Telegram Business Mode, май 2026) и автоматически отвечает ученикам от его имени — принимает переносы, проверяет расписание, блокирует личное время.

---

## Проблема

Репетитор с 15–25 учениками тратит 20–30 минут в день на переписку про переносы. Ученики пишут хаотично, расписание меняется каждый день. Это не потеря лидов — это ежедневный раздражитель который съедает время и нервы.

**Главная боль:** ученики постоянно переносят уроки, и репетитор вынужден вручную перестраивать расписание в реальном времени.

---

## Целевой пользователь

- Репетитор-одиночка, 15–25 учеников
- СНГ (KZ, RU, UA, UZ)
- Telegram — основной канал общения с учениками
- Ведёт расписание в Apple Calendar или Google Calendar
- Не технарь, не готов настраивать сложные CRM
- Готов платить $18–25/месяц за реальное решение

---

## Как работает (ключевой флоу)

```
Ученик пишет репетитору в Telegram:
"Можно перенести среду 17:00 на пятницу?"
        ↓
Chat Automation перехватывает сообщение
        ↓
Бот проверяет календарь репетитора:
- пятница свободна? → да
- это не личное время? → верно
        ↓
Бот отвечает ОТ ИМЕНИ РЕПЕТИТОРА:
"Да, пятница 17:00 подходит, перенёс ✓"
        ↓
Календарь обновляется автоматически
        ↓
Репетитор видит актуальное расписание
— без единого сообщения с его стороны
```

## MVP — что входит

### 1. Онбординг (всё внутри Telegram, никакого сайта)
- Репетитор находит `@TutorBot` → пишет `/start`
- Бот задаёт вопросы по одному: предметы → классы → рабочие часы → цена
- Бот присылает ссылку для подключения Google Calendar (OAuth — мини-страница для callback неизбежна)
- В конце бот говорит: "Теперь иди в Settings → Business → Chatbots → введи @TutorBot"
- Репетитор делает это → бот активируется и начинает перехватывать сообщения

### 2. Автоответ на переносы
- Бот получает сообщение об отмене или переносе
- Парсит дату/время через GPT-4o
- Проверяет свободные слоты в календаре
- Отвечает от имени репетитора:
  - Если слот свободен → подтверждает и обновляет календарь
  - Если занят → предлагает 2–3 альтернативных времени
  - Если непонятно → уточняет у ученика

### 3. Блокировка личного времени
- Репетитор пишет боту: "Пятница 19:00–23:00 — бар с друзьями"
- Бот добавляет блок в календарь
- Это время никогда не предлагается ученикам

### 4. Контекст по ученику
- У каждого ученика в БД: имя, предмет, класс, стандартное расписание, история изменений
- Бот подтягивает контекст по Telegram user_id при каждом сообщении
- При переносе уточняет "какой урок?" только если неясно

### 5. Уведомление репетитору
- Если бот не уверен в ответе → пуш репетитору с черновиком
- Репетитор одобряет или правит — одна кнопка
- Все автоматические действия логируются

### 6. Утренняя сводка
- Каждое утро в 9:00 репетитор получает в Telegram:
  - Расписание на сегодня
  - Что изменилось вчера
  - Новые запросы если есть

## За бортом v1 (не делаем)

- Оплата уроков онлайн
- Генератор домашних заданий (идея хорошая — v2)
- Guest Bots для групп (v2)
- Bot-to-Bot (v2)
- Мультиязычность
- Групповые уроки
- Напоминания ученикам перед уроком (24h-окно ограничение)
- Веб-дашборд (только Telegram-интерфейс в v1)
- Apple iCloud CalDAV (v1.1 fast-follow, не v1)

## Технический стек

| Компонент | Решение |
|---|---|
| Python | 3.12 |
| Telegram Bot | aiogram 3.28+ |
| Chat Automation | Telegram Bot API — Business Mode + `businessConnectionId` |
| AI | OpenAI GPT-4o (парсинг интентов, генерация ответов) |
| Календарь | Google Calendar через OAuth (Apple — v1.1 fast-follow) |
| БД | PostgreSQL 16 (host-native, не Docker для dev) |
| Бэкенд | Python + FastAPI + SQLAlchemy 2.x async + Alembic |
| Onboarding | FSM (Finite State Machine) в aiogram |
| Деплой | Railway |

## Метрики успеха MVP

- Репетитор подключился и бот обработал первый перенос без его участия ✓
- 0 жалоб на "бот ответил неправильно" за первую неделю
- Репетитор не отключил бота после первых 7 дней
- Время на переписку: с 20–30 мин/день до < 5 мин/день
